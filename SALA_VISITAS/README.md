# SALA DE VISITAS — CONTEXTO PORTÁTIL

**Status:** ACTIVE / INTEROPERABILITY LAYER  
**Created:** 2026-10-29  
**Purpose:** permitir que modelos sin acceso al ecosistema Umbral completo trabajen con suficiente contexto de Osvaldo, sus líneas editoriales y el patrimonio relevante.

## Metáfora operativa

Umbral es la casa.

Este repositorio es la sala de visitas.

Aquí puede haber mesa, silla, teléfono y documentos que también existen dentro de la casa, porque algunos colaboradores no tienen llave del resto.

## Regla

`PORTABLE COPY != CANONICAL SOURCE`

Cada documento portable debe indicar:
- procedencia;
- fecha;
- estado;
- si es síntesis, snapshot o contexto editorial;
- qué autoridad puede modificarlo.

## Qué sí vive aquí

- voz y escritura de Osvaldo;
- contexto editorial suficiente;
- líneas PERSONAL / VIDA AMPLIA y PROFESIONAL / BAJO FILTRO;
- resumen operativo de Umbral;
- AIDOH para contexto de contenido;
- notas editoriales de Jaula de Oro;
- notas editoriales de Vida Amplia;
- inventario B-roll;
- catálogo portable de Universidades;
- reglas de uso para modelos externos.

## Qué no vive aquí

- secretos;
- credenciales;
- código de productos;
- expedientes personales de operadores;
- historias identificables de terceros;
- infraestructura interna irrelevante;
- todo el Búnker.

Si una copia portable contradice una decisión humana posterior de Osvaldo, gana la decisión humana posterior y debe registrarse como `CURRENT_OVERRIDE`.
